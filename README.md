# security-lab

Personal laboratory for cybersecurity training: notes, checklists, and exercises.

## Scope

This repository documents **authorized** learning only:
- home lab / VMs I own
- official platforms (TryHackMe, Hack The Box, similar)
- publicly documented techniques used for education

No exploits against third-party systems. No credentials. No live targets.

## Structure

```
security-lab/
  01-linux/          Linux fundamentals and hardening notes
  02-networking/     TCP/IP, packets, Wireshark, services
  03-web-security/   OWASP-oriented web notes
  04-labs/           Write-ups from legal practice platforms
  resources.md       Curated learning resources
```

## Status

Early stage. Folders will be filled as topics are completed, not in advance.

## Stack I am building around

- Linux (CLI, systemd, permissions, networking tools)
- Wireshark / tcpdump
- Git and markdown documentation
- Python for small security scripts (later)

## How I work

1. Theory for one concept
2. Practice in a controlled lab
3. Short written notes in this repo
4. Next concept only after the previous one is usable
